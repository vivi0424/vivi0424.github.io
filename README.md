# Виктория Деборина — портфолио

Личный сайт-портфолио: компьютерная лингвистика, NLP, LLM и анализ данных.

**Сайт:** https://vivi0424.github.io · **English version:** https://vivi0424.github.io/en/

## Что на сайте

- **Проекты**
  - [Корпус 1000](https://github.com/vivi0424/Russian_short_stories_1000) — база персонажей и их взаимодействий в 1000 русских рассказах XX века, извлечённых с помощью LLM;
  - [LLM и функции Проппа](https://github.com/vivi0424/HSE_Introduction-to-Prompt-Engineering-) — сравнение 5 языковых моделей в разметке волшебных сказок;
  - «Эмоциональная карта» LiveLib — разметка отзывов по 26 эмоциям и дашборд в Yandex DataLens;
  - «Цифровой архивариус» для ПАО «Северсталь», [RAG и классификация текстов](https://github.com/vivi0424/HSE-Computational-linguistics).
- **Наука** — публикации (в том числе Scopus и Springer) и доклады на конференциях.
- **Навыки и контакты**, резюме в PDF на русском и английском.
